🍔 Landing Page de Restaurante

Uma landing page moderna, totalmente responsiva e interativa com tema de restaurante, construída utilizando HTML5, CSS3 e JavaScript. O projeto apresenta um design limpo, elegante e com animações suaves para encantar os visitantes.

🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

HTML5: Marcação semântica e estruturação da página.

CSS3: Estilização avançada, design responsivo e efeitos visuais.

JavaScript: Funcionalidades dinâmicas e interatividade.

jQuery: Facilitação na manipulação do DOM e eventos.

ScrollReveal: Biblioteca para animações suaves ao rolar a página.

Font Awesome: Ícones vetoriais para interface.

Google Fonts: Tipografia moderna e personalizada.
